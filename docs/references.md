# Reference verification

Verification date: **25 November 2026**. These checks concern source identity and the claims described below; they do not independently reproduce the cited studies. Access dates in the original proposal refer to an earlier consultation and are not evidence of this project's access. Live documentation versions can differ from the versions actually installed for the benchmark; the tested dependency lock is authoritative for execution.

## Statistical review notes

The following are engineering and statistical review recommendations for this benchmark, rather than claims attributed to the papers above.

- Freeze split assignment before evaluation. Never search seeds or regroup scaffolds based on held-out performance. Any label use for random stratification is part of the predefined split procedure.
- Preserve one group for every empty Bemis-Murcko scaffold. Large groups can prevent a close 60/20/20 split and can dominate the cluster bootstrap; report their size and the realized partition proportions.
- Cache resampled folds by ordered training IDs, labels, feature definition, sampler settings, random state, and dependency/code version. A cache keyed only by assay or split seed can leak validation examples.
- Bootstrap differences with identical indices for each paired method and baseline. Resample scaffold groups with replacement, retaining every example each time a group is drawn. Repeated draws create repeated observations. Cluster-bootstrap sample size varies; recompute the top-ten-percent selection count for each replicate.
- Define undefined metrics explicitly for bootstrap replicates with one class or zero positives, and report valid replicate counts per metric. Do not silently count undefined AUC as zero or treat missing replicates as successful observations.
- Use a stable, label-independent compound-ID tie breaker for top-k metrics. Repeated bootstrap copies can use occurrence order as a tertiary key. AP and PR curves should retain the scoring library's tied-score convention.
- A strictly increasing sigmoid preserves ranking in exact arithmetic. Check slope direction, ordering, and floating-point ties, and do not present an unchanged ranking metric as a calibration gain. A negative fitted slope is a reversal that must be disclosed.
- Seed standard deviations describe split/fit variation. Within-partition bootstrap intervals describe conditional test-set uncertainty, not uncertainty from retraining or generalization to all possible assays. Three seeds do not establish a reliable population-level inference, and overlapping test sets are not independent replications.
- Report balancing-minus-unbalanced deltas; positive is favorable for AP, AUC, precision, and recall, whereas negative is favorable for Brier score and log loss. Comparisons are numerous and unadjusted intervals should be described as descriptive, without claims of multiplicity-controlled significance.
- Similarity thresholds must be fixed before viewing outcomes. Any subset with fewer than 20 positive examples is exploratory. Scaffold separation does not imply that all test fingerprints have low similarity to training examples.
- Assay activity is an experimental endpoint, not a diagnosis of human toxicity. The final conclusions should concern model performance, calibration, uncertainty, and limitations only.
